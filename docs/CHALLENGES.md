# Challenge-Leitfaden

SQL parameterisieren; XSS encodieren; IDOR über Eigentümer prüfen; Authentifizierung mit Hash, Session und Limit schützen; Uploads allowlisten und ausserhalb Webroot speichern; SSRF ausschliesslich über feste lokale Mock-Kennungen erlauben. Jede Challenge enthält Lernziel, Aufgabe, Hinweise, Auswirkung, erwartetes Verhalten und OWASP-Quelle.
